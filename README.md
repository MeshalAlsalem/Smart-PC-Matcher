# 🖥️ Smart PC & Laptop Matcher

An intelligent recommendation system built with Python and Streamlit that helps users find their perfect computer hardware. Whether you need a pre-built laptop or a custom PC build, this tool analyzes your budget and requirements to provide the best matching specifications.

## 🌟 Overview
Choosing the right computer can be overwhelming due to the sheer number of specifications and price points. This project acts as a smart tech advisor. By inputting criteria such as budget, desired performance, and specific use cases, the system processes these details and outputs tailored recommendations. 

### 💻 Advanced Custom Web Interface (Streamlit)
Unlike basic or lightweight web interfaces, this project utilizes **Streamlit** to build a robust, custom frontend. This allows for dynamic sidebars, interactive dropdowns, and real-time filtering, offering a highly professional and responsive user experience.

## 🚀 Key Features
- **Dynamic Recommendations:** Adapts outputs based on whether the user is looking for a Laptop or a Desktop PC.
- **Custom PC Builds:** Generates complete, balanced PC part lists optimized for the user's specific financial capability.
- **Budget & Specs Analysis:** Intelligently balances cost vs. performance to ensure the user gets the best value.

## 🛠️ Tech Stack
- **Language:** Python
- **Frontend Framework:** Streamlit (Custom Interactive UI)
- **Core Logic:** LangChain & AI Recommendation Engine
